# Eka Nanda Sari — Professional Portfolio

Corporate Modern English-language portfolio website.

## Run locally
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. GitHub Pages will publish the site at https://ekaanasution.github.io/eka-nanda-sari-portfolio/.

## Edit content
Edit `index.html` directly in GitHub. Search for section IDs such as `about`, `expertise`, `projects`, `experience`, and `contact`.

## Data note
Dashboard visuals and sample figures are illustrative only, not actual company data. Confirm dates, metrics, contact details and project attribution before external use.
